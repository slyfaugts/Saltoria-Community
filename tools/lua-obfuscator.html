Level Obfuscation
Makin tinggi, makin kuat
🟢 Ringan
Enkripsi semua string literal + hapus komentar. Paling aman, cocok buat script yang sering di-update.
🟡 Sedang
Level Ringan + rename semua variabel/fungsi lokal jadi nama acak (nama field table tetap aman, tidak ikut di-rename).
🔴 Berat
Level Sedang + samarkan angka literal + sisipkan kode sampah di awal tiap fungsi.
