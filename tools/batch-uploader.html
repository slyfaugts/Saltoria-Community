📤 UPLOAD TOOL

Batch Uploader

Upload banyak gambar, audio, model, animasi, atau video ke Roblox sekaligus lewat Open Cloud. Lihat status tiap file, lalu ekspor semua Asset ID sebagai tabel Luau, CSV, atau JSON.

1 · Kredensial

API key hanya dikirim lewat proxy Saltoria ke Roblox pada saat upload dan tidak disimpan di browser maupun server. Key harus punya izin asset:read dan asset:write, dan IP/akun pembuat harus sesuai izin key.

Yang didukung

Gambar → Decal.png .jpg .jpeg .bmp .tga
Audio.mp3 .ogg .wav .flac
Model.fbx .gltf .glb .rbxm .rbxmx
Animation.rbxm .rbxmx (pilih tipe di tabel)
Video.mp4 .mov
Batas ±4,3 MB per file karena request lewat proxy serverless; file lebih besar (umumnya video) ditandai dan dilewati. Animation: file .rbxm/.rbxmx yang dibuat di luar Roblox Studio bisa ditolak Roblox. Animasi hanya bisa dipakai di experience milik creator yang sama. Untuk membuat animasi, pakai Animation Studio.
