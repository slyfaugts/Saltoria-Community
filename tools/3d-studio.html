Teks 3D

Rata teks

Detail lebih rendah berarti segitiga lebih sedikit dan lebih ringan untuk Roblox. Font dengan banyak lengkungan butuh detail lebih tinggi.

Efek teks

Positif melengkung seperti pelangi, negatif seperti senyum. Berlaku per baris.

Warna

Gambar dipotong persegi dari tengah. Dipasang otomatis ke seluruh permukaan (UV otomatis dari proyeksi depan).

Warna dan gradient mengikuti seluruh permukaan, termasuk sisi samping. Aktifkan opsi di atas jika sisi samping ingin memakai satu warna khusus.

Preset material

Preset mengatur metalik dan kekasaran, dan untuk teks serta gambar bisa ikut mengatur warna. Roblox hanya membawa tekstur warna dari GLB, jadi cahaya neon cuma tampil di pratinjau. Untuk efek neon sungguhan, set Material = Neon pada MeshPart.

Relief (permukaan timbul)

Gaya bertingkat dibuat dari lapisan bertumpuk (berundak). Gaya halus membuat permukaan heightmap: makin rapat kisi, makin halus dan makin banyak segitiga (dibatasi otomatis oleh target). Relief halus mengikuti tonjolan secara landai dan menyatu dengan dasar di tepinya.

Bentuk

Radius mengatur seberapa besar tepi ketebalan dibulatkan; Kebulatan 1 = potongan miring, 3 sampai 6 = membulat halus (segitiga bertambah). Jika batas segitiga terlampaui, outline disederhanakan otomatis. Tepi di bagian yang terlalu tipis dikecilkan sendiri.

Cara import ke Roblox Studio

Lewat GLB (disarankan)

  1. Klik Unduh .glb di bar bawah.
  2. Di Studio buka Home → Import 3D, pilih file .glb, lalu Import.
  3. Kalau ukurannya terlalu besar atau kecil, ubah Size pada MeshPart.
  4. Atur Material ke SmoothPlastic dan Reflectance ke 0 supaya warna lebih bersih.
  5. Jaga model di bawah 20.000 segitiga.

Lewat OBJ

  1. Klik Unduh .obj + texture dan ekstrak file zip-nya.
  2. Import model.obj lewat Import 3D.
  3. Unggah logo_texture.png di Asset Manager, lalu isi TextureID pada MeshPart.
