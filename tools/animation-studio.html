Joint Editor

Mengedit joint di waktu tanpa keyframe otomatis membuat keyframe baru. Rotasi dalam derajat (urutan XYZ), posisi dalam studs.

Konversi R6 ↔ R15

R6→R15: rotasi Torso/Neck/Shoulder/Hip dipetakan ke joint R15, joint lain (Waist, Elbow, Knee, dst.) diisi netral. R15→R6: Waist digabung ke Torso; Elbow/Knee/Wrist/Ankle tidak punya padanan dan hilang.

Preset Pose / Animasi

Preset otomatis menyesuaikan rig (R6/R15). Menggantikan keyframe yang ada, bisa di-Undo.

Export Keyframe Animation

.rbxmx bisa di-drag ke Roblox Studio (jadi KeyframeSequence) lalu di-publish lewat Animation Editor. Keyframe di detik 0 otomatis ditambahkan saat ekspor bila belum ada, supaya hasil di Roblox sama dengan preview.

Upload ke Roblox

API key dibuat di Creator Hub → Open Cloud → API Keys: tambah Assets (read & write) dan set IP ke 0.0.0.0/0. Key hanya dikirim ke server saltoria.site untuk diteruskan ke Roblox, tidak disimpan. Karena IP dibuka lebar, pakai key khusus dengan masa berlaku singkat dan hapus setelah selesai.

Penting: animasi yang diupload hanya bisa dipakai di experience milik creator yang sama (akun atau grup). Roblox juga bisa menolak file .rbxmx yang dibuat di luar Studio; kalau upload gagal, download .rbxmx, buka di Studio, lalu publish lewat Animation Editor.
