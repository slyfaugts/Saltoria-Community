Asset Permission

Beri izin pakai banyak aset (audio, animasi, decal) sekaligus ke akun, grup, atau experience lain. Aset tetap privat, tapi bisa dipakai di game milik penerima izin. Semua jalan di browser.

1Akun pemilik aset

API Key dari akun atau grup yang memiliki aset.

Izin API Keydibutuhkan
asset-permissionsWrite
Buat di Creator Hub → Open Cloud → API Keys dari akun/grup pemilik aset. Isi IP: 0.0.0.0/0.
Cara membuat API key
  1. Buka Creator Hub → Open Cloud → API Keys, klik Create API Key.
  2. Beri nama bebas, lalu tambahkan sistem API asset-permissions dengan operasi Write. Untuk fitur isi nama otomatis, tambahkan juga assets dengan Read.
  3. Buat key dari akun atau grup yang memiliki aset. Untuk aset grup, pilih grupnya saat membuat key.
  4. Di bagian IP, isi 0.0.0.0/0, lalu simpan.
  5. Salin key (hanya tampil sekali) dan tempel di kolom di atas.
Nama menu di Roblox bisa sedikit berbeda dari waktu ke waktu.

Key disimpan hanya di localStorage bila dicentang. Saat dikirim, key lewat proxy Saltoria hanya untuk meneruskan request ke Roblox.

Opsional. Pemilik sebenarnya ditentukan oleh API key; isian ini untuk memastikan key dan aset berasal dari akun/grup yang benar, dan tampil di konfirmasi.

Pengaturan lanjutan

Roblox tidak mengizinkan request langsung dari browser, jadi dibutuhkan proxy. Bawaan: /api/proxy (fungsi serverless di deployment ini). Kosongkan untuk memakai bawaan.

2Beri izin ke

Isi akun/grup pemilik game, atau Universe ID experience.

Klik target untuk memilihnya. Centang kotak kecil di kiri untuk menambah tujuan lain sekaligus. Menghapus dari daftar ini tidak mencabut izin di Roblox.

Sebelum kirim
Izin yang sudah diberikan tidak bisa dicabut lewat API Roblox. Open Cloud hanya punya endpoint pemberian izin. Cabut manual per aset:
  1. Buka Creator Dashboard.
  2. Buka aset yang ingin dicabut izinnya.
  3. Masuk ke bagian Permissions.
  4. Hapus akun/grup tersebut dari daftar.
Jika API Key kurang scope, Roblox bisa membalas sukses tanpa menerapkan apa-apa. Tool ini menandainya sebagai tak terkonfirmasi.
3Pilih aset

Tab hanya memisahkan daftar. Tipe aset dikenali Roblox dari Asset ID.

Deteksi aset otomatis eksperimental
Memuat aset yang pernah di-upload oleh pemilik aset (langkah 1) sesuai tab yang aktif. Hasilnya masuk ke daftar dalam keadaan belum dipilih. Fitur ini memakai endpoint Roblox yang tidak resmi untuk API key, jadi bisa saja ditolak. Kalau gagal, pakai impor file atau tempel ID.
